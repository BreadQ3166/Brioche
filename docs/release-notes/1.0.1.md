# Brioche v1.0.1

## 核心修复：彻底根治局域网与外网频繁断联

1. **修复被控端 `asyncio.StreamWriter` 并发写入竞争与过短超时**
   - 此前视频发送主循环（视频帧 / 音频 / 统计）与输入接收协程（`pong` 心跳 / 切屏错误）并发调用同一条加密连接的 `writer.drain()`，且写入超时仅 `4s`，在局域网大帧突发、Wi-Fi 抖动或 DERP 波动时容易触发连接异常中断。
   - 现已为每条连接引入写锁严格串行化 `send()`，并将 `drain` 超时提升至 `15s`、读取超时提升至 `25s~30s`。
2. **修复双端 TCP Keepalive 与 Nagle 延迟缺失**
   - 服务端与控制端同步开启 `TCP_NODELAY` 与系统级 `SO_KEEPALIVE`（Linux/macOS/Windows 均配置 15s 探测），并在内置 `brioche-network` TCP 转发隧道上同步开启 KeepAlive，防止路由器/NAT/Wi-Fi 静默回收连接。
3. **修复自动重连时触发“被控端已有活动连接”导致永久断开**
   - 此前控制端断线后 1 秒即重连，而被控端旧的半开连接尚未超时释放 `SessionGate`，导致重连被拒并停止重试。
   - 现已支持同一认证端携带 `reconnect` 标记无缝接管旧的半开会话，同时保留对不同设备并发连接的独占保护。
4. **修复硬件编码短暂停顿与内置网络轮询误杀活跃会话**
   - `HardwareEncoder.frame()` 遇到静默画面或短暂模式切换时保持心跳存活，不再 4 秒直接报超时断开。
   - `brioche-network` 外网状态轮询超时不再强杀 `brioche-network` 子进程，且将节点探测限制在 6 秒内完成，避免波及正在进行的远程会话与文件传输。
5. **稳固默认串流引擎与 Rust `brioche-core` v2.0 引擎**
   - 默认模式稳定使用多标签集成引擎（完整自动重连、剪贴板、Opus 音频、双栏文件管理、多屏切换），`v2.0` Rust 原生 UDP/GPU 窗口改为显式按需启用。
   - 修复 `brioche-core` 中 `ffmpeg` 路径发现、QUIC 45s 空闲保活、多会话接管以及对称 UDP Ping 打洞保活（穿透防火墙/NAT）。

## 新功能：支持指定局域网连接与仅局域网直连锁定

- **顶部栏新增 `⚡ 指定局域网连接` 入口**：输入局域网 IPv4（或点选附近自动发现的设备），一键立即通过局域网直连，绝不经过 Tailscale 外网或 DERP 中继。
- **设备独立配置新增 `仅局域网直连（不走外网）`（`lan_only`）**：锁定后若局域网离线或未绑定 IP，绝不会静默回退到外网中继；设备卡片同步显示 `LAN 锁定` 状态徽章。
- **设备详情抽屉与右键菜单增强**：支持一键“仅通过局域网直连”、“指定/修改局域网 IP 连接”、右键快速切换“锁定为仅局域网直连”，以及双通道设备按需指定局域网或外网连接；局域网会话同样支持自动重连与 DHCP IP 自动刷新。
