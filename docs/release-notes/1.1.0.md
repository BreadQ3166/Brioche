# Brioche v1.1.0

## 全面三阶段性能重构：GPU 全链路加速 + 零拷贝内核 + v2.0 生产闭环

### 阶段 A：默认集成引擎全平台 GPU 加速与节能提速
- **GPU OpenGL YUV420p/YUV444p + CAS 锐化着色器（`gpu_canvas.py`）**：控制端默认直接上传解码后的平面 YUV 到 GPU 纹理，在显卡着色器中完成 BT.709 YUV→RGB 转换与对比度自适应锐化（CAS），**彻底消除 CPU 色彩转换与 4K 33MB/帧 `QImage` 深拷贝**；无 GL 环境自动回退 `QPainter`。
- **事件驱动零轮询渲染**：废除 `6ms QTimer` 轮询，改用去重信号 `frame_ready` 即时唤醒绘制，消除额外帧抖动。
- **多编码器硬件解码探测与静止桌面降帧**：`DesktopDecoder` 支持 H.264 / HEVC / AV1 并自动探测 `VideoToolbox` / `CUVID` 硬件解码；`DesktopEncoder` 增加亚毫秒采样脏帧检测，静止桌面自动降至 2 FPS 心跳并在首像素变化时 0ms 瞬时唤醒。
- **内置媒体组件升级（`build_media.py`）**：Linux/Windows 随包 `ffmpeg` 全面启用 `hevc_nvenc`、`av1_nvenc`、`h264_cuvid`、`hevc_cuvid`、`d3d11va` 及裸流复用/解复用，不再依赖系统安装外部 `ffmpeg`。

### 阶段 B：Rust `brioche-core` 零拷贝采集、进程内硬编硬解与真实 ABR/PLI 闭环
- **全平台零克隆采集（`brioche-capture`）**：`ScreenCapturer::grab_frame_ref()` 在 Linux MIT-SHM 直接借用共享内存切片、Windows DXGI 静止帧（`AccumulatedFrames == 0`）完全跳过 GPU 回读与 33MB 克隆、macOS 复用帧缓冲。
- **macOS 12+ 进程内原生 `VideoToolbox` 硬件编解码（`macos_vt.rs`）**：纯 Rust C-FFI 直调 `VTCompressionSession` / `VTDecompressionSession`（H.264 & HEVC），**零 `ffmpeg` 子进程、零管道**，支持零重启实时动态调码率（ABR）与瞬时强制 IDR（PLI）。
- **Linux/Windows NVDEC 硬件解码 + 真实 TWCC ABR 与 PLI 闭环**：解码器自动启用 `hevc_cuvid` / `h264_cuvid` / `d3d11va`；Host 收到 `PLI` 立刻触发 `encoder.force_idr()` 消除花屏，TWCC 拥塞控制同步驱动 `encoder.update_bitrate()` 与 FEC 冗余比例。

### 阶段 C：`brioche-core` v2.0 生产闭环与一键极速连接
- **音频、双向剪贴板、自动重连与实时性能 HUD**：`brioche-core` 原生窗口新增 10ms 加密 UDP 音频传输、QUIC 双向剪贴板同步、断线指数退避自动重连，以及窗口标题栏实时显示 `分辨率 · 编码/4:4:4 · FPS · RTT · 码率 · 解码器`。
- **内置 Tailscale WAN UDP 隧道接口**：`EmbeddedNetwork.open_udp_tunnel()` 与 `Host.core_udp_port` 打通内置 `brioche-network` `:47997/udp` 转发。
- **一键入口**：设备详情抽屉与右键菜单新增 **「🚀 v2.0 Rust UDP/GPU 极速直连」**，随时一键切换体验原生 Rust UDP + RS-FEC + wgpu 引擎。
