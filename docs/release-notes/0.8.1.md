Brioche 0.8.1：Mac 被控采集修正、关闭收起与 Ubuntu 频闪排查。

- Mac：替换 MSS 9 中图像引用释放异常的采集实现，逐帧释放拥有的 CGImage／CFData，不释放借用的数据提供者；保留 Retina 尺寸与行填充处理。连接前检查共享所需权限，设置显示当前权限状态，VideoToolbox 未输出首帧时关闭并回退软件 H.264。
- 远程窗口直接显示权限、采集和连接超时错误，避免错误后仍显示“等待画面”。
- 关闭主窗口收起到托盘；桌面不提供托盘时最小化。共享及传输继续运行。托盘菜单或设置中的“退出 Brioche”完全关闭。
- Ubuntu 增加“防频闪对照”采集策略，绕过 FFmpeg X11／NVENC，使用 MSS＋软件 H.264。修改后结束连接、重新开启共享生效；该模式用于定位与兼容，可能降低帧率，不代表已解决所有实际显示驱动／合成器频闪。

提供 Windows、Ubuntu、Intel macOS12 与 Apple Silicon macOS12 安装包。Mac 包保留严格的每个原生库最低系统／架构检查，未经 Apple 公证；仍需在 Intel macOS12 实机验证屏幕录制、辅助功能及真实连接。双方建议更新。
