# Brioche 1.3.0

**Android 客户端全面功能对齐桌面端！** 现在手机端 APK 不再只是局域网精简版，而是完整具备内置 Tailscale 外网、远端文件管理器、Opus 低延迟系统音频、四标签工作台与单设备独立配置的旗舰移动客户端。

## Android 客户端重大升级

- **内置 Tailscale (`tsnet`) 外网直连（免装 VPN / Tailscale 客户端）**
  - 内嵌针对 `arm64-v8a` / `x86_64` 交叉编译的 `brioche-network` (`tsnet`)，自动读取 Android 系统 DNS 并内置多组容灾 DNS。
  - 在 APP 内点击「登录 Tailscale」跳转官方授权页登录后，自动发现并探测同账号所有 Ubuntu / Windows / macOS 电脑，显示直连 / DERP 中继路径与共享状态，一键公网远程控制或传文件，断线自动重建隧道重连。
- **完整远端文件管理器与高速文件互传**
  - 支持在主界面设备卡片或远程桌面工具栏一键打开电脑目录，快捷访问桌面/下载/文档/各磁盘根目录。
  - 支持多选上传手机文件到电脑当前目录、下载电脑文件/文件夹到手机 `Download/Brioche/`、新建文件夹、重命名、删除空目录，全程逐文件 SHA-256 校验。
  - 独立「传输」标签页实时显示上传/下载进度条、速度（MiB/s）、取消任务及限速预设（不限速 / 20 / 8 / 2 MiB/s）。
- **Opus 低延迟系统音频播放**
  - 使用 Android 原生 `MediaCodec (audio/opus)` + 低延迟 `AudioTrack`（48kHz 立体声）解码播放电脑系统音频，远程工具栏支持一键静音/恢复。
- **桌面级四标签工作台 + Light / Dark 双主题**
  - 底部四栏：「设备」（搜索 + 全部/在线/外网/局域网/收藏筛选 + 单设备独立配置弹窗：星标、备注名、专属画质/帧率、🔒锁定仅局域网直连）、「最近」、「传输」、「设置」（浅色/深色/跟随系统主题、默认画质/音频/触控模式、Tailscale 账号管理）。
- **沉浸远程会话增强**
  - 新增可开关的详细**性能 HUD**（编解码器、分辨率、渲染/编码 FPS、RTT、采集/发送耗时、码率、链路路径、音频状态）、画面**缩放模式**（适应 / 填满 / 1:1）、17 项桌面常用组合键（`Ctrl+C/V/A/Z/S`、`Alt+Tab/F4`、`Win+D`、`Ctrl+Shift+Esc`、`Ctrl+Alt+Del`、右键/中键、`F5/F11` 等）。

## 全平台构建
- `Brioche-1.3.0-android.apk`（Android 8.0+，含 `arm64-v8a` & `x86_64` 内置 Tailscale 组件）
- `brioche_1.3.0_amd64.deb`（Ubuntu x64）
- `Brioche-1.3.0-windows-x64.zip`（Windows x64）
- `Brioche-1.3.0-macOS12-arm64.zip` & `Brioche-1.3.0-macOS12-x86_64.zip`（macOS 12+）
