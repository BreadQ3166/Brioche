Brioche 0.8：桌面设备卡片、双向文件互传与macOS12兼容构建。

- 以桌面图示呈现设备，轻量悬停、页面过渡、圆角下拉框，可在设置减少动态效果。
- 原生远程窗口“文件互传”：发送本地文件，或请对方选文件返回。接收方确认目录、独立TLS、SHA256校验、同名另存、取消清理。最多32个文件／64 GiB，限速约1 MiB/s；暂不支持目录递归、断点续传及网页传文件。
- Intel Mac12优先，采用Go1.26.11 / Tailscale1.102.5的独立网络模块，固定Python3.11.18及Mac12兼容依赖，逐个原生库检查最低12.0与架构。提供屏幕录制／辅助功能授权入口，尝试VideoToolbox并支持软件回退。

Mac包未经Apple公证，需要用户通过系统界面允许打开与屏幕／输入权限。构建及新版Mac运行检查不等于已在你的Intel Mac12实机完成验收，请实际验证登录、连接、屏幕和输入；软件不会关闭系统保护。

Ubuntu/Windows继续支持局域网、同账号外网、多屏、2K默认、可选源屏匹配及低延迟设置。Windows解压完整ZIP运行Brioche.exe，Mac解压对应架构ZIP后将Brioche.app放入应用程序。两端建议更新。
