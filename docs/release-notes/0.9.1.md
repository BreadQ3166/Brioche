# Brioche 0.9.1

稳定性与画质热修版本（Phase 0 止血更新，后续主线将进入 `brioche-core` 下一代 Rust + UDP/WebRTC 零拷贝串流内核阶段）。

## 修复与改进

### macOS 12 稳定性修复
- **彻底修复连接多屏主机并切换显示器时的闪退问题（`SIGSEGV`）**：
  - 将远程会话顶部悬浮工具栏中的显示器选择器由自定义透明弹窗 `RoundedComboBox` 替换为原生 `QPushButton + QMenu`（`MonitorMenuButton`），并延迟派发切换事件至菜单卸载后，彻底规避 Qt 6.7 `libqcocoa.dylib` 在 `NSWindowAccessibility` 与 autorelease pool 中的悬空指针崩溃。
  - 在 macOS 上禁用 `RoundedComboBox` 对 `QComboBoxPrivateContainer` 强制施加无边框透明窗口标志，一并消除设置页与抽屉下拉框的同源崩溃风险。

### Ubuntu / NVIDIA NVENC 闪屏与画质修复
- **消除 4 Hz 周期性闪糊**：将 `HardwareEncoder`（`h264_nvenc`）的关键帧间隔由 `fps/4`（每 0.25 秒强插 IDR）调整为 `max(30, fps*2)`，码率控制由 1 帧极小缓冲的 `CBR` 升级为 `VBR + multipass qres + spatial-aq` 并放宽 VBV 缓冲，显著降低关键帧画质波动与闪烁感。
- **大幅提升 4K/2K 桌面文字清晰度**：将 NVENC 降采样滤镜由 `fast_bilinear` 升级为 `lanczos+accurate_rnd`（原生分辨率下跳过多余缩放），编码预设升级至 `p4`，软件/VideoToolbox 编码器降采样升级为 `BICUBIC`。
- **HiDPI / Retina 1:1 像素对齐**：修复远程画布「原始像素 1:1」模式在高分屏下的逻辑缩放比例计算。
