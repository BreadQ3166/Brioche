# Brioche 1.2.1

紧急修复 Android 客户端 `v1.2.0` 安装后无桌面图标、且无法从系统设置启动的问题，并完善 Android 自适应图标与全屏沉浸适配。

## 本次修复

- **修复 Android 桌面图标缺失与无法启动**：修正 `AndroidManifest.xml` 中 `MainActivity` 启动器类别误写为 `android.intent.category.CATEGORY_LAUNCHER` 的问题，改为标准 `android.intent.category.LAUNCHER`，恢复桌面图标显示与系统设置「打开」入口，并增加 `launchMode="singleTop"`。
- **标准 Android 自适应图标 + 全密度 Mipmap 图标**：新增 `mipmap-anydpi-v26/ic_launcher.xml`（`<adaptive-icon>`）及 `mdpi`/`hdpi`/`xhdpi`/`xxhdpi`/`xxxhdpi` 高清 PNG 图标，兼容 MIUI / HyperOS / ColorOS / OriginOS / HarmonyOS / 原生 Android 各类桌面启动器。
- **刘海屏与沉浸全屏优化**：主界面启用 `fitsSystemWindows` 避免状态栏遮挡，远程会话在 `onWindowFocusChanged` 自动重新进入沉浸全屏。
- **CI 自动防回归校验**：GitHub Actions 构建阶段新增 `aapt2 dump badging` 强制校验，确保打包产物必须声明可启动的 `com.brioche.android.MainActivity`。
