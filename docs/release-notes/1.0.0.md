# Brioche 1.0.0

Brioche 1.0.0 正式集成下一代 **Rust 原生低延迟串流内核（`brioche-core` v2.0 架构）**，并保持对现有 `v0.9.x` 协议、双栏远程文件管理器与内嵌 Tailscale 组网的完全向后兼容。

## 核心架构升级

### 1. 全新 Rust 原生串流内核（`brioche-core`，四平台内置）
- **加密 UDP + 多条带 RS-FEC + 零队头阻塞**：采用 32 字节紧凑 Brioche-UDP v3 帧头、逐包 ChaCha20-Poly1305 AEAD 认证加密 + 128 位防重放窗口，以及纯 Rust GF(256) Cauchy Reed-Solomon 多条带前向纠错（单帧最高支持 22 MB 4K/8K YUV 4:4:4 IDR，丢包 0 RTT 无损还原）+ 闭环 NACK/PLI/TWCC 动态码率控制（ABR）。
- **证书钉扎 QUIC 控制平面**：基于 `quinn` + TLS 1.3 SHA-256 指纹钉扎的可靠多路复用通道，专载键鼠输入、原子切屏与独立硬件光标同步，不与视频流争抢带宽。
- **Tailscale 原生 UDP 隧道支持**：升级内嵌 `brioche-network` (`tsnet`)，新增 `:47997/udp` 转发与 `udp_tunnel` 支持，为跨网 UDP-over-WireGuard 打下通道基础。

### 2. 三平台原生采集、硬编与 `wgpu` GPU 着色器直出渲染
- **全平台原生采集与输入**：
  - **Ubuntu 22.04+**：X11 MIT-SHM 共享内存采集 + XFixes 硬件光标分离 + XTest 注入 + 瓦片脏帧节流；
  - **Windows 10/11**：原生 **DXGI Desktop Duplication (`IDXGIOutputDuplication`)** + Win32 **`SendInput`**；
  - **macOS 12+ (Intel & Apple Silicon)**：纯 CoreGraphics C FFI 采集与 **`CGEventPost`** 注入（严格兼容 macOS 12.0 ABI，彻底规避 `HIToolbox` 主线程崩溃）。
- **HEVC (H.265) + YUV 4:4:4 文字锐利模式**：支持常驻零延迟 `hevc_nvenc` / `h264_nvenc` / `VideoToolbox` 推流，无 4Hz 周期闪糊。
- **`wgpu`（Vulkan / Metal / D3D12）原生渲染窗口**：WGSL 片元着色器在 GPU 端直接完成 YUV420P/YUV444P → BT.709 RGB 转换 + CAS 文字对比度锐化 + 分离硬件光标合成，事件驱动呈现（无 6ms 定时轮询抖动），支持 `F11` 全屏、`Ctrl+Alt+1~9` 原子切屏与 `Ctrl+Alt+S` 实时切换锐化。

### 3. 主界面一键无感升级与兼容回退
- 设置页「画面与性能」新增 **v2.0 引擎模式选择**、**YUV 4:4:4 文字锐利开关** 与 **GPU/编码器实时探测状态**。
- 局域网点击连接时通过受现有 TLS 证书钉扎与 Token 保护的 `v2_negotiate` 自动协商升级至 Rust 原生 GPU 窗口；若对端为旧版 `v0.9.x` 或用户选择兼容模式，自动回退至 v1.x 会话窗口。
