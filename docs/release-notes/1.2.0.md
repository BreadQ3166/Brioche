# Brioche v1.2.0

## 全新平台：正式新增原生 Android 安卓 APP（`Brioche-1.2.0-android.apk`）

- **零拷贝硬件解码渲染**：基于原生 Kotlin + Android `MediaCodec`（H.264 / HEVC 低延迟硬件解码）直出 `SurfaceView`，无需 CPU 软解或帧拷贝，手机/平板端流畅省电。
- **全功能安全互通桌面端**：
  - 完整实现 Brioche v2 钉扎 TLS 协议（强制 SHA-256 证书指纹校验，防中间人攻击）。
  - 内置局域网组播自动发现（`239.255.47.95:47993`）与六位配对码首次安全配对，兼容 Ubuntu / Windows / macOS 桌面端。
  - 支持 **⚡ 指定局域网 IP 直连**、Tailscale IP 直连与 `brioche://` 连接凭据深链/粘贴连接。
  - 支持 2 秒心跳保活与网络波动自动重连。
- **专为触屏设计的沉浸式控制体验**：
  - 支持**精准触控板模式**（单指相对滑动、轻点左键、双指右键与双指滚动）和**直触模式**一键切换；
  - 顶部可折叠悬浮工具栏：实时 FPS / RTT / 码率 HUD、多显示器切换、软键盘输入桥接、常用快捷键菜单（`Ctrl+C/V`、`Alt+Tab`、`Esc`、`Win/Cmd`、`Ctrl+Alt+Del`）以及双向剪贴板同步。
- **CI 自动化五平台发布**：GitHub Actions 现已同步构建、单元测试并签名发布 **Ubuntu (.deb)、Windows (.zip)、macOS Apple Silicon (.zip)、macOS Intel (.zip) 以及 Android (.apk)** 五端安装包。
