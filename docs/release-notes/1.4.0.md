# Brioche 1.4.0

**全面切换内置外网引擎为 EasyTier v2.6.4（免费、无设备数上限、全球 P2P 极速直连 + 国内低延迟公共中继）！** 彻底告别 Tailscale 海外 DERP 高延迟与繁琐浏览器授权流程，桌面端与 Android 客户端开箱即用。

## 核心升级

- **全新 EasyTier 账号/网络登录（桌面端 + Android 同步升级）**
  - 点击「登录 EasyTier」只需填写相同的**网络名称**与**网络密钥**，即可一键将 Ubuntu / Windows / macOS / Android 设备组成端到端加密的 P2P 网格网络。
  - 默认内置多组已验证在线低延迟公共引导节点（`tcp://183.230.36.171:11010`、`tcp://easytier.weiai.org.cn:11010`、`tcp://et.sumnight.top:11010`、`tcp://225284.xyz:11010`），并支持随时替换为自定义/自建节点。
- **纯用户态零权限架构（`--no-tun` + `--use-smoltcp` + 严格端口白名单）**
  - 无需管理员权限、无需安装虚拟网卡驱动、Android 无需 Root 或 VPN 权限。
  - 启用 `--latency-first`（智能选择最低延迟链路）与 `--enable-kcp-proxy`（大幅降低 4G/5G 弱网丢包延迟），并严格限定 `--tcp-whitelist 47984 47985 --udp-whitelist 47987` 仅暴露 Brioche 加密端口。
  - Android 端打包体积大幅瘦身，内置静态编译 `easytier-core` / `easytier-cli`，彻底消除 Android 11+ `netlinkrib` 沙箱冲突。
- **全平台同步构建与校验**
  - `Brioche-1.4.0-android.apk`（Android 8.0+，内置 `arm64-v8a` & `x86_64` EasyTier v2.6.4）
  - `brioche_1.4.0_amd64.deb`（Ubuntu x64）
  - `Brioche-1.4.0-windows-x64.zip`（Windows x64）
  - `Brioche-1.4.0-macOS12-arm64.zip` & `Brioche-1.4.0-macOS12-x86_64.zip`（macOS 12+）
