Brioche 0.7：可选远程分辨率、源屏匹配和低延迟视频链路。

- 主界面直接选择720p、1080p、2K或原生（最高4K），默认2K，局域网与外网共用并记住选择。
- 可勾选“源屏也匹配”：临时调整被控 Ubuntu Xorg 屏幕，正常断开后恢复；保留方向、位置和桌面画布。异常退出下次启动重试恢复，用户手动更改的模式和布局不会被覆盖。默认不改变本机显示。仅查看共享不允许源屏匹配，Windows被控端暂不支持该项。
- NVENC显式关闭输出等待和前瞻，限制队列，取消第二次帧率等待，保留采集时间戳，不以重复帧填充固定帧率。四切片匹配软件解码线程，原生画布使用BGRA32位像素。
- 性能面板增加源屏与串流尺寸、实际绘制、发送等待、主机帧龄、解码及颜色转换耗时。

隔离2K短测中，仅将NVENC输出等待从3帧改为0帧，抓取开始到压缩帧就绪平均耗时约46→22ms；这是主机链路对照，不是键鼠端到端或Windows双机延迟验收。78项源码测试与隔离GUI流程通过；包含模式选择、竖屏、多屏恢复、失败回滚、崩溃记录恢复和只读权限。

Windows：解压完整ZIP后运行Brioche.exe。两端都更新后，建议先选2K；需要降低4K抓屏成本时，显式勾选“源屏也匹配”再连接Ubuntu。普通启动无需另外安装Python、Go、FFmpeg或Tailscale。源屏匹配使用Ubuntu已有的xrandr，无需管理员权限。

仍不承诺2K60/90/144实际达标，当前没有DXGI/D3D11零拷贝、原生硬件解码或macOS12支持。预发布版本，Windows未签名。
