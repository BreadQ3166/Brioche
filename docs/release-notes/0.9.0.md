Brioche 0.9.0：现代统一工作台、Light/Dark 双主题、多标签沉浸会话、双栏文件管理器、双向剪贴板、断线自动重连与 Opus 系统音频。

- 统一设备工作台与双主题：合并局域网与同账号外网设备目录（同名自动聚合双通道并默认局域网优先），新增 Warm Paper（暖白浅色）与 Dark Roast（深烘深色）及跟随系统主题；支持关键词搜索、分类筛选、分组侧栏与「最近连接」；单击卡片打开右侧独立配置抽屉（备注名、分组、收藏、单设备分辨率/帧率/码率/优先通道）；设置页重构为双栏分类布局。
- 多标签沉浸远程窗口与悬浮控制：同一窗口多标签并发连接多台电脑，支持不断连拆分为独立窗口；全新深色毛玻璃顶部悬浮胶囊工具栏（支持左右拖动、闲置自动收起与图钉固定）、右上角可拖拽实时性能 HUD、底部自动消退提示气泡、三种画面缩放模式（适应 / 原始 1:1 / 铺满）与组合键快捷菜单（Ctrl+Alt+Del、Alt+Tab、Win/Cmd、锁屏等）。
- 办公刚需与输入体验升级：新增断线无感自动重连（指数退避、保留安全/证书/权限错误不重试边界）、防回声死循环双向文本剪贴板同步（自动/手动/禁用切换）、长按按键重复、水平滚轮与 Mac↔Win 修饰键互换；被控端新增始终置顶可折叠桌面悬浮控制条（Host Pill），支持一键暂停/恢复对方键鼠输入与断开。
- 局域网发现与双栏文件管理器：新增零依赖局域网多播自动发现广播（不含凭据）与证书指纹 DHCP 变 IP 自动追踪；设置页支持逐台查看并单独撤销已配对局域网设备；新增双栏远程文件管理器（本机/远端目录并排浏览、新建文件夹、重命名、安全删除、无人值守双向文件与文件夹递归互传、画布拖拽上传），解除 1 MiB/s 限制并提供最高不限速/20/8/2 MiB/s 速率挡位与实时速度显示。
- Opus 低延迟系统音频：复用内置 PyAV libopus 编解码，Linux 支持 PulseAudio/PipeWire 系统回环音频采集与低延迟播放，工具栏提供一键静音与音量调节（其他平台优雅降级不影响视频）。

提供 Ubuntu 22.04 DEB、Windows 11/x64 便携 ZIP 以及 macOS 12（Intel x86_64 与 Apple Silicon arm64）安装包。建议控制端与被控端同步更新至 0.9.0。
