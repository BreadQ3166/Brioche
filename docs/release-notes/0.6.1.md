Brioche 0.6.1：视频节拍修正、客户端像素转换优化与分段性能统计。

- 硬件流由 FFmpeg 负责采集帧率，发送端不再施加第二次帧率等待。
- 原生客户端使用 Qt 适合的 BGRA 32位像素，减少颜色转换和绘制开销。保留独立像素所有权，支持旧 RGB24 帧。
- 性能面板增加源屏与输出尺寸、实际绘制 FPS、发送等待、解码、颜色转换及绘制耗时。
- NVENC 取帧等待与软件采集编码耗时分别标注，避免将等待压缩帧的时间误认为 GPU 编码耗时。
- 局域网、同账号外网、多屏、配对及网页访问流程保持兼容。

67 项源码测试与隔离 GUI 测试通过。Windows 与 Ubuntu 安装包来自相同提交的成功自动构建，并验证校验值及必要运行库。

这是性能修正和诊断版本，**不保证消除所有低帧率问题，也不代表已经达到2K60/90/144**。4K 源屏即使串流2K，仍需要采集完整4K；当前 Xorg/GDI 采集、CPU 解码和系统内存复制仍可能限制帧率。本版不会自动调整物理显示分辨率。

Windows 解压完整 ZIP 后运行 Brioche.exe，两端建议都更新。Ubuntu 可安装 DEB。无需另外安装 Tailscale、FFmpeg、Python 或 Go；当前仍不支持 macOS12。预发布版本，Windows 未签名。
