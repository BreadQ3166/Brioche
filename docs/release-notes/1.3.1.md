# Brioche 1.3.1

修复 Android 端内置 Tailscale 外网模块启动即退出（提示「内置网络模块已退出，请重试」）的根因问题。

## 修复内容

- **真正针对 Android Bionic/NDK 原生编译 (`GOOS=android` + `CGO_ENABLED=1`)**：改用 Android NDK Clang (`aarch64-linux-android26-clang` / `x86_64-linux-android26-clang`) 交叉编译内置 `libbrioche_network.so`，彻底避免此前 `GOOS=linux` 在 Android 沙箱下触发 `seccomp` 系统调用限制与 `SO_MARK` 失败的问题。
- **绕过 Android 11+ SELinux `netlinkrib` 限制**：在 `network-helper` 新增 `--android-safe` 与 `--ifaces`，启动前调用 `netns.SetEnabled(false)` 并通过 `netmon.RegisterInterfaceGetter` 注入 Android `ConnectivityManager` 真实网卡列表 + 实时 UDP 出站 IP 探测，彻底避免 `route ip+net: netlinkrib: permission denied` 导致的启动崩溃。
- **完善环境变量与诊断透传**：为内嵌 `tsnet` 设置 `XDG_CONFIG_HOME` / `XDG_CACHE_HOME` / `TS_NO_LOGS_NO_SUPPORT=true`，并在 `EmbeddedNetwork.kt` 采集 `stderr` 与退出码，任何异常均直接显示具体原因。
